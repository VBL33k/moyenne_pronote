# Extension Calculatrice de Moyenne Pronote

## Description
Cette extension Chrome calcule automatiquement votre moyenne générale à partir des notes affichées sur Pronote.

## Fonctionnalités
- ✅ Calcul automatique de la moyenne générale
- ✅ Affichage des moyennes par matière
- ✅ Indicateur visuel sur la page Pronote
- ✅ Interface moderne et intuitive
- ✅ Compatible avec tous les établissements Pronote

## Installation

### Méthode 1 : Installation depuis le Chrome Web Store (recommandée)
1. Téléchargez l'extension depuis le Chrome Web Store
2. Cliquez sur "Ajouter à Chrome"
3. L'extension sera automatiquement installée

### Méthode 2 : Installation manuelle (mode développeur)
1. Téléchargez le fichier ZIP de l'extension
2. Extrayez le contenu dans un dossier
3. Ouvrez Chrome et allez dans `chrome://extensions/`
4. Activez le "Mode développeur" en haut à droite
5. Cliquez sur "Charger l'extension non empaquetée"
6. Sélectionnez le dossier contenant l'extension

## Utilisation

### Calcul automatique
1. Connectez-vous à votre espace Pronote
2. Naviguez vers la page des notes (bulletin, relevé de notes, etc.)
3. L'extension calcule automatiquement votre moyenne
4. Un indicateur apparaît en haut à droite de la page

### Utilisation du popup
1. Cliquez sur l'icône de l'extension dans la barre d'outils Chrome
2. La moyenne générale s'affiche automatiquement
3. Cliquez sur "Recalculer" pour mettre à jour les données
4. Cliquez sur "Détails par matière" pour voir les moyennes par discipline

## Compatibilité
- ✅ Chrome (version 88+)
- ✅ Edge (version 88+)
- ✅ Tous les établissements utilisant Pronote
- ✅ Pages : bulletins, relevés de notes, évaluations

## Fonctionnement technique
L'extension analyse le contenu de la page Pronote pour :
1. Détecter automatiquement les notes (format "15/20", "15,5/20", etc.)
2. Identifier les matières associées
3. Calculer les moyennes par matière et générale
4. Afficher les résultats dans une interface moderne

## Dépannage

### L'extension ne détecte pas mes notes
- Vérifiez que vous êtes bien sur une page Pronote contenant des notes
- Actualisez la page et réessayez
- Assurez-vous que les notes sont au format numérique (ex: "15/20")

### La moyenne semble incorrecte
- Cliquez sur "Recalculer" dans le popup
- Vérifiez que toutes vos notes sont bien affichées sur la page
- Contactez le support si le problème persiste

### L'extension ne s'active pas
- Vérifiez que l'extension est bien installée et activée
- Rechargez la page Pronote
- Redémarrez Chrome si nécessaire
